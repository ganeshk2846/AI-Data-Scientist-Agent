## 1. Executive Context and Corrected Product Scope

The intended product operates under a clean, focused architectural paradigm:

$$\mathbf{ONE\;USER} \;\longrightarrow\; \mathbf{ONE\;ACTIVE\;DATABASE\;CONNECTION} \;\longrightarrow\; \mathbf{ONE\;DATABASE\;ENGINE\;AT\;A\;TIME}$$

### Supported Database Engines:
- **SQLite**
- **PostgreSQL**
- **MySQL**

### Scope Boundaries:
1. **Single User, Single Active Database:** The application operates with **one active database at a time**. It does **NOT** require multiple users, multi-tenant partitioning, simultaneous multiple database registrations, concurrent cross-database routing, or complex tenant authorization systems.
2. **Clean Intelligence Reset upon Disconnection:** When the user disconnects the current database and connects another, the application cleanly resets the active database's intelligence (catalog, vector collection, BM25 index, semantic definitions, relationship graph) while preserving internal application state (`agent_app.sqlite`), application settings, and essential conversation history.
3. **Database-Independent Application Core:** The application core contains zero hardcoded table names, column names, SQL formulas, or fixed date boundaries. It adapts dynamically to whichever database is currently connected.
4. **Real Development Database Verification:**
   - **Inspection & Confirmation:** The repository was inspected and confirmed to contain **`ecommerce.db`** (219,873,280 bytes, SQLite 3 format, 46 tables, 8 views, 29 indexes, 2,418,138 rows) at `C:\D_drive\AI_FOR_BI_P\ecommerce.db`.
   - **Primary Development Fixture:** `ecommerce.db` is the primary development and baseline validation database.
   - **Read-Only Verification:** `ecommerce.db` is strictly accessed via read-only connections (`mode=ro`). Its schema and data are immutable and never modified by the application or tests.
   - **Git Protection:** `ecommerce.db` is strictly excluded from Git tracking via `.gitignore` (`*.db`).
5. **Real Local LLM Provider:**
   - Provider: **Ollama** running locally on `http://localhost:11434`.
   - Model: **`qwen3:4b`** (verified installed and available in local Ollama instance).
   - **Strict No-Mocking Policy:** Mock LLM implementations must not be used in application runtime, demonstrations, or end-to-end integration tests. If Ollama is unavailable, the application reports a clear connectivity error rather than returning fake results.
